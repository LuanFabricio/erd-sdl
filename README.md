# Description
A simple (work in progress) Entity Relationship Diagram (ERD) visualizer using an Specific Domain Language to build.

# Basic dependencies
- `gcc` (>= 16.1.x)
- `Raylib` (>= 6.1)
- `make` (>= 4.4.x)

# Build and run
```bash
make run # builds and runs
# or
make         # build
./build/main # run
```
